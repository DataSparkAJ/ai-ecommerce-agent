## 🧠 AI Ecommerce Insight Agent

Multi-Agent Business Intelligence System Powered by Gemini

📌 Overview

The AI Ecommerce Insight Agent is a multi-agent analytics workflow that automates e-commerce performance reporting.
It replaces manual Excel/Python work by:

* Loading and cleaning e-commerce data

* Calculating sales & profitability KPIs

* Generating visual insights (charts)

* Producing a professional PDF business report

* Writing strategy insights using Gemini

* Outcome: Reliable data-driven recommendations for pricing, discounting, and category/region strategy — without requiring a full-time analyst.

## ❓ Problem Statement

* E-commerce teams rely heavily on raw exports from Shopify, Amazon, and ERPs.
Manually analyzing these datasets is:

* Time-consuming and repetitive

* Prone to human error

* Limited to surface-level metrics

* Lacking actionable insights

Teams struggle to answer critical questions:

* Which categories actually drive profit?

* Do discounts increase conversion or reduce margin?

* Which regions are worth expanding into?

* Where is the business leaking profit?

## 💡 Solution

This project implements a multi-agent system for automated business intelligence.

Agent	                    Responsibility
DataAgent                 Loads & preprocesses CSV/Excel data
AnalysisAgent	            Computes KPIs & business metrics
VizAgent	                Generates visualizations (PNG)
InsightAgent (Gemini)	    Writes analyst-grade insights
ReportAgent	              Produces a professional PDF report

## 📌 Only KPI summaries are sent to Gemini (not full data)
→ Low cost, fast inference, and focused context.

🏗 Architecture Flow
main.py
   ↓
DataAgent          →  Load & clean dataset
   ↓
AnalysisAgent      →  Compute sales & profit KPIs
   ↓
VizAgent           →  Generate static charts
   ↓
InsightAgent       →  Summarize + recommend using Gemini
   ↓
ReportAgent        →  Build final multi-page PDF

## 📊 KPIs Generated by the System

## ▶️ How to Run

1) Install dependencies

pip install -r requirements.txt


2) Update dataset path (inside main.py)

path = r"D:/your_dataset.csv"


3) Execute

python main.py


4) Enter Gemini API key (requested at runtime — not stored)

5) Output Files

* PDF Report (*.pdf)

* Charts (*.png)

* Logs in terminal with [LOG] trace

## 🔐 API Security

* API key collected only via input()

* Never stored or logged

* If accidentally exposed, regenerate in Google AI Studio
